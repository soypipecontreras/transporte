# Contexto del negocio para construir la app

Copia de la carpeta de contexto del proyecto (normativa, operación y especificación) para que el equipo la use al construir el producto. Fuente: `D:\ANDRES\Transporte\contexto`, actualizada el 14 de octubre de 2026.

## Por dónde empezar

1. `00_INICIO/00_LEEME_PRIMERO.md`: mapa general, glosario y actores.
2. `05_ESPECIFICACION_APP/`: visión, roles, módulos, reglas de negocio, modelo de datos, pantallas, roadmap del MVP y el prompt base para Claude.
3. `01_NUCLEO_COMUN/`: normativa (Decreto 1017, RNDC, SICE-TAC), puertos, ciclo del viaje, finanzas, crédito, seguros, antifraude y protección de datos.
4. `02_MODELO_A_VENTA_DE_LA_APP/05_PRODUCTO/`: MVP para la transportadora aliada, implementación y soporte.
5. `06_PLANTILLAS_Y_CHECKLISTS/`: documentos que la app debe pedir y verificar.
6. `07_FUENTES/`: fuentes y documentos oficiales.
7. `90_FUTURO/04_TRANSPORTE_INTERNACIONAL/`: funcionalidad internacional, fuera del MVP.

## Qué no está aquí

Este repositorio es público. Se dejaron por fuera los clientes, los contratos y borradores legales, el modelo financiero, los precios, los aliados, el Modelo B y la guía de pendientes. Algunos documentos los mencionan (por ejemplo `08_CLIENTES` o `09_DOCUMENTOS...`); esas rutas solo existen en la carpeta privada.
